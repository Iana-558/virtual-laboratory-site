## Задание

Задание размещено в папке task в файле README.md.

## Вариативная часть задания

Создать Telegram-бота на языке Python, который выполняет следующие функции:

1. Отвечает на команды `/start`, `/labs`, `/tip [тема]`.
2. Распознаёт ключевые слова «цепь», «реакция», «клетка» и выдаёт соответствующие инструкции.
3. Содержит модификацию на основе изученного туториала (смена тематики с гороскопа на образовательную).
4. Интегрирован с проектом «Виртуальная лаборатория» и представлен на сайте проекта.
