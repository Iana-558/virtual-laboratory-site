## 1. Базовая часть практики: создание веб-сайта

### 1.1. Исследование и планирование

На начальном этапе был проведён анализ требований к сайту. Было определено, что сайт должен включать следующие страницы:

- Главная страница с аннотацией проекта
- Страница «О проекте» с описанием проблематики, целей и задач
- Страница «Участники» с описанием вклада каждого члена команды
- Страница «Журнал» с постами о прогрессе работы
- Страница «Ресурсы» со ссылками на полезные материалы

### 1.2. Выбор технологий

Для реализации сайта был выбран путь А (HTML + CSS без использования генераторов статических сайтов). Это решение было принято в связи с базовым уровнем подготовки и необходимостью гарантированного выполнения задания в установленные сроки.

### 1.3. Процесс разработки

Разработка велась поэтапно:

1. **Создание структуры проекта.** Были созданы папки `css/` и `images/`, файлы `index.html`, `about.html`, `team.html`, `journal.html`, `resources.html`, `bot.html`.

2. **Разработка главной страницы.** Реализовано меню навигации, герой-блок с заголовком, три карточки актуальности проекта, блок со статистикой лабораторных работ, галерея скриншотов приложения, видео-демонстрация, блок с информацией о маскоте и партнёрах.

3. **Разработка страницы «О проекте».** Оформлены карточки проблематики, выделенный блок с целями проекта, таймлайн задач.

4. **Разработка страницы «Участники».** Добавлена информация о каждом участнике команды с подробным описанием личного вклада.

5. **Разработка страницы «Журнал».** Создано пять постов о прогрессе работы с фотографиями, видео и прогресс-баром.

6. **Разработка страницы «Ресурсы».** Добавлены карточки источников по предметам (физика, химия, биология) и полный список использованных материалов.

7. **Разработка страницы о боте.** Создана отдельная страница с описанием целей, задач, технологий, команд и видео-демонстрацией работы Telegram-бота.

### 1.4. Использование Git

В процессе работы над сайтом велась регулярная фиксация изменений в Git-репозитории. Все коммиты сопровождались осмысленными сообщениями. Репозиторий размещён на платформе [GitHub/GitVerse] (указать нужное).

### 1.5. Трудности и их преодоление

| Трудность | Решение |
|-----------|---------|
| Проблемы с путями к CSS-файлам | Проведена диагностика через консоль браузера, пути скорректированы |
| Отсутствие стилей на некоторых страницах | Временно встроены стили непосредственно в HTML-файлы |
| Изменение структуры репозитория под требования | Все файлы перемещены в соответствии с утверждённой структурой |

### 1.6. Результат базовой части

Создан полностью функционирующий статический веб-сайт из шести страниц, интегрированный с проектом «Виртуальная лаборатория». Сайт содержит текстовые и графические материалы, видео-демонстрации и ссылки на полезные ресурсы.

## 2. Вариативная часть практики: создание Telegram-бота

### 2.1. Выбор темы

В качестве вариативного задания была выбрана тема «Создание Telegram-бота на Python». Выбор обусловлен необходимостью получения практических навыков разработки асинхронных приложений и интеграции с внешними API.

### 2.2. Исследование предметной области

На этапе исследования были изучены:

- Официальная документация Telegram Bot API
- Туториал freeCodeCamp «How to Create a Telegram Bot using Python»
- Документация библиотеки pyTelegramBotAPI

Был проведён сравнительный анализ библиотек для создания ботов (таблица 1).

**Таблица 1 – Сравнение библиотек**

| Библиотека | Сложность | Тип | Область применения |
|------------|-----------|-----|---------------------|
| python-telegram-bot | Высокая | Синхронная/Асинхронная | Крупные проекты |
| pyTelegramBotAPI | Низкая | Синхронная | Начинающие, малые проекты |
| aiogram | Средняя | Асинхронная | Высоконагруженные системы |

Для реализации был выбран `pyTelegramBotAPI` ввиду низкого порога входа и понятной документации.

### 2.3. Процесс разработки

Разработка бота включала следующие этапы:

1. **Регистрация бота.** В Telegram через @BotFather был создан бот с username `@VirtLabAssistant_bot` и получен токен доступа.

2. **Настройка окружения.** Установлены библиотеки `pyTelegramBotAPI` и `requests`.

3. **Написание базового кода.** Реализован обработчик команды `/start`.

4. **Добавление функционала.** Разработаны обработчики команд `/labs` (список лабораторных работ) и `/tip` (советы по темам).

5. **Обработка ключевых слов.** Добавлен обработчик естественного языка, распознающий слова «цепь», «реакция», «клетка».

6. **Модификация.** На основе туториала freeCodeCamp (бота-гороскопа) выполнена модификация: изменена предметная область с развлекательной на образовательную, добавлены новые команды и улучшена обработка ошибок.

### 2.4. Тестирование

Тестирование проводилось в ручном режиме. Были проверены:

- Все текстовые команды (`/start`, `/labs`, `/tip физика`, `/tip химия`, `/tip биология`)
- Ключевые слова («цепь», «реакция», «клетка»)
- Обработка некорректного ввода

Все функции работают в штатном режиме.

### 2.5. Трудности и их преодоление

| Трудность | Решение |
|-----------|---------|
| Проблемы с подключением к Telegram API из-за блокировок | Использован Cloudflare Warp для обхода ограничений |
| Отсутствие опыта работы с библиотекой | Изучена официальная документация и примеры |
| Необходимость интеграции бота с сайтом | Создана отдельная страница `bot.html` с описанием и ссылкой |

### 2.6. Результат вариативной части

Создан функционирующий Telegram-бот, который:
- Приветствует пользователя командой `/start`
- Выводит список лабораторных работ по команде `/labs`
- Даёт советы по физике, химии и биологии по команде `/tip`
- Распознаёт ключевые слова и выдаёт инструкции

Код бота размещён в папке `src/bot.py`.
