Telegram-бот ассистент

Помощник по лабораторным работам «Виртуальной лаборатории»

Цель и задачи

Цель: Создать Telegram-бота, который поможет ученикам быстро получать справочную информацию по лабораторным работам, а также освоить технологию создания ботов на Python.

Исследование

Изучить документацию Telegram Bot API и библиотеку pyTelegramBotAPI

Разработка

Создать бота с командами /start, /labs, /tip и обработкой ключевых слов

Тестирование

Проверить работу всех функций и исправить ошибки

Документация

Оформить техническое руководство и встроить бота в экосистему проекта
